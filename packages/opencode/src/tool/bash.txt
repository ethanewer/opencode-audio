Executes a command in a persistent shell session.

The shell session persists across tool calls: directory changes, environment variables, and virtualenvs carry over.

Be aware: OS: ${os}, Shell: ${shell}

All commands start in ${directory} by default. The working directory persists across calls.

For large outputs, a truncated view is shown. The full output is saved to the log file — use Read with offset/limit or Grep to inspect it.

Usage notes:
  - You can specify an optional timeout in milliseconds. Default: 300000ms (5 minutes).
  - When issuing multiple independent commands, make multiple Bash tool calls in parallel.
  - ${chaining}
  - Use ';' only when you need to run commands sequentially but don't care if earlier commands fail.
  - You can use `cd` freely — directory changes persist. Use `workdir` to set a temporary working directory for a single command.
