Fetch content from a URL and return it as markdown, text, or HTML. Use this to read documentation, API references, blog posts, or any web page.

Usage notes:
  - The URL must start with http:// or https://
  - Format options: "markdown" (default, converts HTML to readable markdown), "text" (strips tags), or "html" (raw)
  - Images are returned as base64-encoded attachments
  - This tool is read-only and does not modify any files
  - Large responses are truncated to fit context limits
